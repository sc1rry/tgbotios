# Чистая версия PWA

Замените содержимое репозитория GitHub Pages этими файлами целиком.

Файлы:
- index.html
- style.css
- app.js
- manifest.json
- service-worker.js
- icons/

После загрузки:
1. Commit changes.
2. Подождать GitHub Pages 1–2 минуты.
3. Открыть сайт с `?clean=1`.
4. Сделать Ctrl+Shift+R.
